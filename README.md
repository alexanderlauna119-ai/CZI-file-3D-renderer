A Python-based tool for 3D visualization and analysis of fluorescence microscopy images. It supports ZEISS .czi files, including multi-channel images and Z-stacks, allowing microscopy data to be explored and visualized in 3D.

Built using PyVista and VTK, the tool includes automated metadata extraction, physical voxel scaling, intensity thresholding, noise reduction, and 3D distance measurements. It also supports exporting 3D visualizations and models in several formats, including .html, .glb, .ply, and .png.

Developed with Python 3.12, with a focus on making 3D microscopy visualization and spatial analysis more accessible.
